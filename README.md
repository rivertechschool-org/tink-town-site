# Tink Town

Public website: https://tink.town/

The static Tink Town website. GitHub Pages serves this repository from the root of `main`, using the custom domain in `CNAME`.

Tink Town is a brand of River Tech LLC. The site links to https://rivertech.llc/ for the wider story.

The enquiry form prepares an email draft in the visitor’s mail app; it does not send or store submissions.
